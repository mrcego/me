# César Gómez | Senior Vue/Nuxt · AI-Assisted Craft

Personal portfolio for **César Gómez** — senior Vue/Nuxt and fullstack delivery with honest AI-Assisted Craft (Vibe Coding Cleanup), not an “AI & NLP Expert” or dedicated AI Engineer title.

Built with **Nuxt 4**, **Vue 3**, and **Motion-V**. Glassmorphism UI, micro-interactions, and full EN/ES internationalization. Live at [cesargomez.dev](https://cesargomez.dev).

## Key features

- Hire-focused home plus bilingual expertise landings (Vue, Vibe Coding Cleanup, Node)
- Case studies (Colegium, LingoQuesto), Cartagena local landing, and AI-Assisted Craft methodology page
- Dynamic theming, PrimeVue + Tailwind 4, SSR/SSG for SEO
- Machine-readable context: [`public/llms.txt`](./public/llms.txt), [`public/ai.txt`](./public/ai.txt)

## Tech stack

- **Framework**: [Nuxt 4](https://nuxt.com/) (Vue 3)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/) via Vite
- **Animations**: [Motion-V](https://motion-v.com/)
- **Icons**: [Nuxt Icon](https://nuxt.com/modules/icon)
- **i18n**: [@nuxtjs/i18n](https://i18n.nuxtjs.org/) — canonical locales in `i18n/locales/`
- **UI**: [PrimeVue 4](https://primevue.org/)
- **SEO**: [@nuxtjs/seo](https://nuxtseo.com/) + Robots + Sitemap
- **Image**: [@nuxt/image](https://nuxt.com/modules/image)
- **Package manager**: pnpm

## Getting started

### Prerequisites

- Node.js 20+
- [pnpm](https://pnpm.io/)

### Install & develop

```bash
pnpm install
pnpm dev
```

App runs at `http://localhost:3000/`.

## Build & validate

```bash
pnpm lint
pnpm typecheck
pnpm generate
pnpm prepush:validate
```

Preview a production build:

```bash
pnpm preview
```
